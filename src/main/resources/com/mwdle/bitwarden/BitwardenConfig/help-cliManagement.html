This section allows you to manage the Bitwarden Command Line Interface (CLI) executable used by the plugin. The plugin will automatically download the CLI on first startup if it's not found.

Check Version: A safe, read-only action that displays the version of the currently installed bw executable. This is useful for verifying that the CLI is installed and functioning correctly.

Download Latest: Forces a fresh download of the latest official Bitwarden CLI. Warning: This will overwrite the existing executable. This is useful for updating the CLI to a newer version without needing to restart Jenkins.
