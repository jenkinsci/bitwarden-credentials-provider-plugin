Select a Jenkins Username with password credential that stores your Bitwarden API Key.

  • Username: Your Bitwarden Client ID.
  • Password: Your Bitwarden Client Secret.

Note: This plugin uses API key authentication. Standard email/password login is not supported, as it is incompatible with accounts that have Two-Factor Authentication (2FA) enabled.

Verifying Configuration:

After you click Save or Apply, the plugin will attempt to connect and sync in the background. To confirm that your settings are correct, you can:

  • Check the main Jenkins system log for a success or failure message.
  • Or, wait a few moments and then navigate to the main Credentials page to see if your Bitwarden items have appeared.
