Specifies how long (in minutes) Jenkins will cache the list of your Bitwarden items.

This duration sets the maximum age for both your credential list and the secret values. A higher value means fewer network calls, but a longer delay before any changes you make in Bitwarden appear in Jenkins.

Behind the scenes, this setting controls how often the plugin runs a bw sync to update the Bitwarden CLI's own local, encrypted database.

Crucially, the plugin never caches your actual secret values (passwords, keys, etc.). They are only "fetched live" from the CLI's local database at the exact moment a build needs them.

This design also means Jenkins can continue to use your secrets even if it temporarily loses its internet connection, as it can read from the last successful sync.

A minimum value of 1 minute is enforced. The default is 5 minutes.
