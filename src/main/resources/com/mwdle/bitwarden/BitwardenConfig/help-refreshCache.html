This button forces a full re-authentication and triggers a background sync of your Bitwarden vault.

This is useful in two main scenarios:

  • You have updated the secret value of your API Key or Master Password credential in Jenkins and need the plugin to use the new secret immediately.
  • You have added or changed items in your Bitwarden vault and want the changes to appear in Jenkins without waiting for the next automatic refresh.

After clicking, you will see a confirmation message that the task has started. To see the updated list of credentials, you may need to refresh the page after a few moments.
