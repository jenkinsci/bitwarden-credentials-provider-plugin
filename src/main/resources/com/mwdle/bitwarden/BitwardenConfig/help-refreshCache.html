This button forces a full re-authentication and triggers a background sync of your Bitwarden vault.

This is useful in two main scenarios:

  • You have updated the secret content of your API Key or Master Password credential in Jenkins (without changing its ID), and you need the plugin to use the new secret immediately.
  • You have added, renamed, or deleted items in your Bitwarden vault and want the changes to appear in Jenkins without waiting for the next automatic refresh.

After clicking, you will see a confirmation message that the task has started.

Note on Saving: If you change the Server URL or select a different credential ID on this page, clicking Save or Apply will automatically trigger this same refresh process. You do not need to click this button after saving those changes.
