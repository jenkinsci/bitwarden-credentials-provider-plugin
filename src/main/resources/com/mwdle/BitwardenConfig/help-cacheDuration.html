Specifies how long (in minutes) Jenkins will cache the list of your Bitwarden items.

A higher value reduces the number of calls to the Bitwarden server and improves UI performance, but it also means there will be a longer delay before newly created or renamed items appear in Jenkins. The content of the secrets themselves is always fetched live and is never cached.

A minimum value of 1 minute is enforced. Default is 5 minutes.
