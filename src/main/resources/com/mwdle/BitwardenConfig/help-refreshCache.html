This button manually starts a background refresh of the list of Bitwarden items from your vault.

This is useful if you have recently added, renamed, or deleted an item in Bitwarden and want to see the changes in Jenkins immediately, without waiting for the automatic cache refresh interval to pass.

After clicking, you will see a confirmation message that the task has started. You may need to navigate away and back to the credentials page after a few moments to see the updated list.
